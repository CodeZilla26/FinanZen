# 💰 FinanZen – Sistema de Control de Finanzas Personales

Aplicación web desarrollada en **Angular (v22)**, **TypeScript**, **Tailwind CSS (v4)** con soporte nativo de **Dark Mode**, arquitectura de **Signals** y preparada para **Firebase**.

## 🚀 Inicio Rápido

```bash
# Instalar dependencias (si es la primera vez)
npm install

# Levantar servidor de desarrollo local
npm start
```

Visita `http://localhost:4200/` en tu navegador.
